nuvolo-nautilus
===============

A GNOME Files extension for `Nuvolo <https://github.com/cyythanapong-netizen/nuvolo-sync>`_.
It shows what Nuvolo knows about each file in your cloud drives and lets you act on it from
the right-click menu.
